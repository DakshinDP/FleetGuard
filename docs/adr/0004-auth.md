# ADR 0004: Keep demo auth self-contained and production auth external

**Status:** Accepted for prototype

**Context:** A one-command hackathon demo must work offline after images and Python dependencies are available.

**Decision:** Use a short-lived HMAC-signed JWT, PBKDF2 password hash, roles, and tenant claims for the local demo. Never accept a tenant override from API input.

**Consequences:** This is not an identity platform. Production must replace it with OIDC, TLS, managed signing keys, key rotation, rate limits, strong audit retention and tested account recovery.
